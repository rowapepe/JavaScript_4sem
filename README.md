## Дополнительное задание
**Условие:** 
* Переделать функцию с сортировкой букв и слов для тегов карточек во вкладке новости

**Решение:**
Добавил теги к карточкам
```javascript
tags: ["транспорт","поезд","метро"]
```
Добавил рендер карточек и сортировку
```javascript
renderNewsList() {
        if (!this.newsRoot) return;

        this.newsRoot.innerHTML = "";

        newsData.forEach((item) => {
            const news = item.product ?? item;
            const tags = Array.isArray(news.tags) ? news.tags : [];
            const sortedTags = this.shouldSortNewsTags ? sortText(tags.join(" ")).split(" ").filter((tag) => tag) : tags;

            renderProduct(
                this.newsRoot,
                {
                    id: `news-${item.id}`,
                    productId: item.id,
                    showDetailsButton: false,
                    ...news,
                    tags: sortedTags,
                },
                null,
            );
        });
    }

    clickSortTags() {
        this.shouldSortNewsTags = true;
        this.renderNewsList();
    }
```
